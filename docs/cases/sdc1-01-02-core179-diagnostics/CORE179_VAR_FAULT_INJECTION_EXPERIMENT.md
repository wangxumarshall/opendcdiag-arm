## 1. 实验目的与设计

### 1.1 为什么用蒙特卡洛 VaR 场景

银行风险引擎做蒙特卡洛 VaR(Value at Risk)计算时,需对"风险因子协方差矩阵 Σ"做 Cholesky 分解(Σ = L·Lᵀ),再用下三角因子 L 把独立正态随机数染成具有相关性的场景因子:x = L·z。Σ 规模 = 投资组合的风险因子数(利率/汇率/股价/信用利差等),典型 256~1024 维。**这正是稀疏 Cholesky 分解(SimplicialCholesky)在金融风控里的真实用途**——也是本实验选它作为 SDC 传导载体的原因:它既是核 179 已确认的触发指令序列(根因报告 §11.2a),又是真实业务负载,二者天然对接。

### 1.2 为什么用故障注入而非活体复现

本实验**故意不**在核 179 上活体复现 SDC,而是用故障注入(纯软件数值替换)模拟 SDC 效果。原因:满载 + 核 179 触发 SDC 会导致系统硬重启(根因报告 §11.3、§16;复现指南 §15 已实证 RCU stall + SBSA watchdog 强制复位,52 分钟挂死)。**在已确认硬件根因的前提下,活体复现的风险(系统不可用)远高于其信息增量**。故障注入能精确控制注入位置/量级,复现性强,且不触碰硬件——是更安全、更可控的实验路径。

### 1.3 注入方法论:整体替换为矩阵内另一个真实对角元

注入方式是把分解出的下三角因子 L 的首对角元 L[0,0] **整体替换**成 L 矩阵里另一个真实的对角元 L[k,k](k≠0),不是构造抽象垃圾值或手工拼接位模式。

**依据**:根因报告 §11.2a 确认的核 179 SDC 机理是"混入的是当时正好活跃在物理寄存器堆(PRF)的另一个 double,整个寄存器值被整条替换"——因此损坏值与正确值的差异是**两个真实的、量级相近但彼此无关的浮点数之间天然的汉明距离**(根因报告 §8.2 实测 21-32 位翻转),不需要刻意拼位。直接用 L[k,k] 整体覆盖 L[0,0] 最贴合真实机理,实现也最简单。

被注入的位置 L[0,0] 也非任意选取:根因报告 §11.2a.A 指出,核 179 的 SDC 损坏经 `L[0,0] = sqrt(d0)` 写入 L 因子首对角元,再经 solve 前向回代 `x[0] = b[0]/L[0,0]`(i=0 时求和项为空)**无衰减放大**到求解结果 x[0]。故 L[0,0] 是 SDC 传导的天然注入点。

### 1.4 基线搭建(简述,不逐轮复述调试过程)

基线经历了几轮修正,每轮对应一个明确问题,此处仅述最终状态与一处值得展开的验证:

- **矩阵生成:独立采样 → 单因子模型**。最初用"每对相关系数独立均匀采样"构造板块相关矩阵 R_s,但 m 维下随机填的非对角值不保证正定(m 大、相关系数偏高时出现负特征值,1e-6 ridge 压不住),Eigen 分解报不正定。改用**单因子模型** `R_s = beta·betaᵀ + diag(1-beta²)`(beta∈[√0.4,√0.8]):秩1半正定 + 正定对角扰动,只要 beta<1 必严格正定,从构造上保证,无需后处理修复。最终 min_eigenvalue=6.37e-02>0。
- **Eigen 分解:SimplicialCholesky → SimplicialLLT + NaturalOrdering**。统一类 `SimplicialCholesky` 无 `matrixL()/matrixU()` 接口(只在具体类 `SimplicialLLT` 上有),故改用 `SimplicialLLT`;并从默认 `AMDOrdering` 换 `NaturalOrdering`(不做填充减少重排序),使消元顺序 k 严格等于输入矩阵行列顺序,L[k,k] 直接对应原始第 k 个风险因子,无需处理置换映射——这对故障注入"说清 L[0,0] 对应哪个风险因子"是必需的。两者都走 `factorize_preordered<false,false>`(LLT)路径,与核 179 SDC 复现环境同源(根因报告 §10.5)。
- **采样方向自检**:用 `L.transpose().triangularView<Upper>().solveInPlace()` 解 Lᵀ·X=Z(反向回代),Cov(X)=Θ⁻¹=Σ。自检用 30000 组样本(与 VaR 情景数 10000 解耦)算经验协方差与 Θ⁻¹ 比,Frobenius 相对误差 5.31e-02 < 0.1 ✅。
- **故障注入实现的 triangularView 视图 bug(值得展开)**:最初把采样从 `solver.matrixU().solveInPlace()` 改用独立 L 副本时,写成 `L.triangularView<Upper>().solveInPlace()`——但 `solver.matrixL()` 提取的副本**只存下三角**,`triangularView<Upper>()` 在其上看到的上三角是空,退化为单位阵,导致采样变成 X=Z(独立正态)、自检误差飙到 0.913、VaR 缩到 0.068。修复为 `L.transpose().triangularView<Upper>()`(transpose 视图把下三角的 L 看成上三角 = Lᵀ),**与 `solver.matrixU().solveInPlace()` 相对差 0.000e+00**(交叉验证),且 `coeffRef(0,0)` 改后视图立即反映新值(注入可见)。这一交叉验证保证故障注入的采样路径与基线严格等价。

## 2. 四组实验完整结果

实验配置:N=512 风险因子,11 个 GICS 板块(单因子模型,板块内相关 0.4~0.8,跨板块 0),sector_seed=42、corr_seed=43(确定性可复现)。每个 SDC 事件注入 L[0,0](IT 板块首因子),20 组随机试验各用不同 donor k(注入 seed=rng_seed+100+t,LCG 选 k∈[50,512)),最坏情况确定性遍历找 |L[k,k]-L[0,0]| 最大的 k_worst。VaR 用 10000 组蒙特卡洛情景(99.9% 组用 50000 组)。

### 2.1 主结果:2×2 对比表(随机/最坏 × 等权/集中)

| | 随机 20 组(均值 / 最大) | 最坏情况(上界) |
|---|---|---|
| **A:等权重**(每因子 1/512≈0.2%) | 0.06% / 0.11% | 0.24% |
| **B:集中权重**(因子0占 20%,其余 511 个平分 80%) | 9.88% / 21.34% | 48.69% |

> **⚠️ 措辞声明(首次出现即讲清):** 上表右下角的 **48.69% 是"两个维度同时取最坏值"——最坏权重配置(集中)× 最坏 donor 选择(k_worst)——构造出的理论上界,不是典型情况、不是预期结果、更不是"正常会发生"的概率估计。** 它是工程构造的偏差上限,用于说明风险敞口的量级范围。四个格子里它最大,正因它是双重最坏的叠加;B 组随机列的 9.88%(均值)才是"集中持仓下单个 SDC 的典型偏差"。本文凡提及 48.69% 或类似上界数字,统一用"理论上界""最坏情况""工程构造的上限"措辞,不单独拎出而不说明其双重最坏性质。

### 2.2 C 组(等权 + 99.9% VaR,单独说明)

另有 C 组:等权重 + P99.9 VaR(n_scen=50000),相对偏差均值 0.03% / 最大 0.10%。与 A 组(等权 + P99,0.06%/0.11%)基本持平甚至略低。这组单独成段在 §3.2 讨论——它反证了"提高置信度能防御单点 SDC"这个直觉。

### 2.3 最坏 donor 详情

k_worst = 462,属于 **Consumer Staples 板块**(板块索引区间 [437,462])。donor L[462,462] = 0.99999999995(≈1.0),原 L[0,0]=1.67326,|diff|=0.673(最大)。

A 组配置(等权)最坏偏差:基线 VaR99=0.259581 → 最坏注入 0.258954,abs=-6.27e-04,rel=-0.24%。
B 组配置(集中)最坏偏差:基线 VaR99=0.343387 → 最坏注入 0.510587,abs=0.167199,rel=48.69%。

### 2.4 注入隔离性自检

20 组随机试验 + 2 组最坏情况,全部通过"L[0,0] 已变 + L 其余元素完全不变"自检(`(L_t - L_baseline).pruned().nonZeros()==1`,纯软件数值替换未误伤别处)。

## 3. 机理分析

### 3.1 "稀释是主因":B 组直接证明

同一注入(试#10, k=501, L[0,0] 1.673→1.275),等权(A 组)VaR 偏差 0.11%,集中权重(B 组,因子0 权重从 0.2% 提到 20%)飙到 21.34%。**权重放大约 103 倍**(0.2%→20%),**偏差放大约 194 倍**(0.11%→21.34%),略超线性。

超线性的来源:VaR 是损失分布的分位数,分位数本身对分布形状的非线性依赖。权重改变后,哪一组蒙特卡洛情景恰好落在分位点附近是非线性的——但主效应仍是权重的线性放大(103× vs 194×,超线性部分是二阶)。这证明:**单点 SDC 的 VaR 偏差基本与受损因子的组合权重成正比,等权组合下被 1/512 稀释掉了**。0.06%~0.24% 的"静默"是稀释的假象,不是 SDC 影响本身小。

### 3.2 "提高置信度救不了稀释":C 组反证(可验证的统计学解释)

C 组(99.9% VaR)相对偏差 0.03%/0.10%,与 A 组(99% VaR)0.06%/0.11% 基本持平,**没有放大**。这反证了"尾部指标对单点 SDC 更敏感"的直觉。

**解释来自可验证的统计学性质,不是经验性的"二阶效应"说法**:精度矩阵 GMRF 采样下,X 是多元高斯的线性组合;单点注入 L[0,0] 改变后,x[0]=b[0]/L[0,0] 的均值被平移(一阶效应),但 X 的协方差结构(方差/形状)主要由 L 的非对角部分决定,单对角元改动对形状扰动小。对高斯分布,分位数 = μ + z_q·σ,**均值平移对所有分位数的影响是等量的,与分位水平 q 无关**。故 P99 与 P99.9 看到的偏差量级相近(0.06% vs 0.03%)。提高 VaR 置信度(99→99.9)这种常见风控加强手段,对均值平移型损坏没有额外防御——因为它只挪动分位点位置,不触及均值平移这个一阶效应。

### 3.3 关于最坏 donor 的机理(经验证,非位置/beta 因果)

差异最大的前 5 名 donor 候选(k=462/482/495/505/511,排序因 C++ 精度微差与 numpy 略有不同但同集)的 L[k,k] 都精确 ≈1.0。**经 Python 验证,这既不是"板块末尾位置"的因果,也不是"beta 弱(载荷弱)→ L 趋近 1"的因果**:

- 前 5 候选的 beta 值(0.66~0.80,均值 0.72)与全体 beta 均值(0.76)接近,前 20 候选 beta 均值 0.7623 几乎等于全体 0.7618——**无系统性偏小**,排除"beta 弱驱动"。
- beta 与板块内位置无结构性关联(单因子模型 beta 是独立均匀采样),排除"板块末尾位置因果"。

真正机理是**小板块经板块内阈值裁剪后的数值现象**:这些候选都来自小板块(Energy 20/Industrials、RealEstate 10、Materials 6、Utilities 13、ConsumerStaples 26)的末尾因子,它们的 Θ_s 行在裁剪后非对角元被裁掉、接近单位行,故 L[k,k] 回归 1.0;而 L[0,0]=1.673 是 IT 板块(大板块、m=149、相关性高)首因子,精度矩阵对角偏大。两者差异最大。**这是数值现象,与位置/beta 无结构性因果**——文档如实写为"小板块裁剪后末尾因子行接近单位行,L[k,k]≈1,与 IT 板块首因子 L[0,0]=1.673 差异最大",不暗示位置有因果。

## 4. 核心结论(可直接支撑论文 motivation)

1. **静默性是权重结构的产物,不是 SDC 影响本身小。** 等权分散组合下 0.06%~0.24% 的偏差不会触发常规风控告警(典型 VaR 限额 breach 阈值在几个百分点),但这是"稀释"的假象——B 组证明同一 SDC 在集中权重下偏差放大到 9.88%(均值)/21.34%(峰值)。

2. **集中持仓下静默失效,且上界惊人。** 同一 SDC 事件,换成集中权重配置,典型偏差到个位数百分比(B 组均值 9.88%);**理论最坏情况(双重最坏叠加:最坏权重配置 × 最坏 donor)可达约 49%**(工程构造的上界,非典型值,见 §2.1 措辞声明)。真实银行业务里,集中持仓(重仓某行业/个股)是常态,等权只是理想化对照组——故 **B 组(尤其均值 9.88%)比 A 组更接近真实业务暴露量级**。

3. **提高 VaR 置信度对这类单点静默损坏无防御效果。** 99%→99.9% 没有放大偏差(0.06%→0.03%),因置信度只影响尾部分位点位置,不影响均值平移这个一阶效应(§3.2 的高斯分位数性质)。这是一个**明确、可操作的风控启示**:对 SDC 类损坏,加强统计置信度无效,需在计算路径层面(如结果校验、冗余计算)设防,而非在统计层。

## 5. 诚实的边界声明

- **合成模拟数据**:本实验的协方差矩阵、风险因子、收益情景均为合成生成(gen_var_cov_matrix.py),**不代表在真实金融机构发现过 SDC**。目的是为论文背景部分提供具体、可量化、技术上站得住脚的现实关联案例,不是针对真实机构的发现。
- **最坏情况是工程上界**:48.69% 及所有"最坏情况"数字是**双重最坏叠加构造的理论上界**(最坏权重 × 最坏 donor),用于说明风险敞口的量级范围,**不是对真实业务发生概率的估计**。真实业务的 donor 分布、权重配置、SDC 发生率均与本实验的构造性设置不同,不可直接外推为"真实银行 VaR 会偏 49%"。
- **注入是机理模拟,非硬件实证**:故障注入用纯软件数值替换模拟核 179 的 PRF 混叠效果(§11.2a 机理),不触及硬件。核 179 硬件层面的真机实证见根因报告 §4-§11(满载复现 + 指令级反汇编),本文不重复硬件证据。
- **单点注入的局限**:本实验只注入 L[0,0](根因报告 §11.2a 指出的核 179 固定损坏点)。真实 SDC 可能发生在 L 的其他位置或 Cholesky 其他阶段,偏差传导路径不同;本文结论限定在"首对角元损坏经 x[0]=b[0]/L[0,0] 放大"这一已确认机理。
